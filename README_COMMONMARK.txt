# Character Bound Item Hider

*Hides character-bound items on the Deposit tab of the bank and house storage chests, where they can never go. Works with keyboard and console.*

**Console Testing Notes:** This addon was developed and tested on **PC / Steam Deck** (using Force Console Flow for console testing).
